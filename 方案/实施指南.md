## 快速开始

### 1. 环境准备

```bash

- Python 3.11+
- Node.js 20+
- ADB (Android Debug Bridge)
- Chrome 浏览器（最新版）

# 安装后端依赖
pip install -e ".[dev]"
```

### 2. 启动开发环境

```bash

# 方式二：手动启动

cd backend
uvicorn app.main:app --reload --port 8000

cd frontend
npm run dev
```

访问：
- 前端：http://localhost:5173
- 后端：http://localhost:8000
- API 文档：http://localhost:8000/docs

### 3. 连接设备

```bash
# USB 连接
adb devices

# TCP/IP 连接
adb connect <device_ip>:5555
```

## 模块开发指南

### 后端模块

#### 目录结构

```
backend/app/
├── domain/          # 领域层（纯业务）
├── application/     # 应用层（用例）
├── infrastructure/  # 基础设施层（实现）
├── interfaces/      # 接口层（HTTP/WS）
└── core/            # 横切关注点
```

#### 开发步骤

1. **定义领域模型**（`domain/`）
   ```python
   @dataclass
   class MyEntity:
       id: str
       name: str
   ```

2. **定义抽象接口**（`domain/ports.py`）
   ```python
   class MyRepository(Protocol):
       async def get(self, id: str) -> MyEntity: ...
   ```

3. **实现应用服务**（`application/`）
   ```python
   class MyService:
       def __init__(self, repo: MyRepository):
           self.repo = repo
       
       async def do_something(self):
           # 业务逻辑
   ```

4. **实现基础设施**（`infrastructure/`）
   ```python
   class SqliteMyRepository(MyRepository):
       async def get(self, id: str) -> MyEntity:
           # SQLite 实现
   ```

5. **暴露接口**（`interfaces/`）
   ```python
   @router.get("/api/my/{id}")
   async def get_my(id: str, service: MyService = Depends(get_my_service)):
       return await service.do_something()
   ```

6. **注册依赖**（`deps.py`）
   ```python
   def get_my_service() -> MyService:
       return MyService(repo=SqliteMyRepository())
   ```

### 前端模块

#### 目录结构

```
frontend/src/
├── components/      # 组件
├── views/           # 页面
├── stores/          # 状态管理
├── services/        # API 服务
├── composables/     # 组合式函数
└── router/          # 路由
```

#### 开发步骤

1. **定义数据类型**（TypeScript）
   ```typescript
   interface MyEntity {
     id: string
     name: string
   }
   ```

2. **实现 API 服务**（`services/`）
   ```typescript
   export const api = {
     async getMy(id: string): Promise<MyEntity> {
       const res = await client.get(`/api/my/${id}`)
       return res.data
     }
   }
   ```

3. **创建 Store**（`stores/`）
   ```typescript
   export const useMyStore = defineStore('my', () => {
     const data = ref<MyEntity | null>(null)
     
     async function fetch(id: string) {
       data.value = await api.getMy(id)
     }
     
     return { data, fetch }
   })
   ```

4. **创建组件**（`components/`）
   ```vue
   <template>
     <div>{{ store.data?.name }}</div>
   </template>
   
   <script setup lang="ts">
   import { useMyStore } from '@/stores/my'
   const store = useMyStore()
   </script>
   ```

## 常见问题

### Q: 设备无法连接？

A: 检查：
1. ADB 是否安装：`adb version`
2. 设备是否授权：`adb devices`
3. USB 调试是否开启

### Q: 视频流延迟高？

A: 优化：
1. 降低分辨率：`stream.max_size=720`
2. 降低码率：`stream.bit_rate=2M`
3. 检查网络延迟

### Q: 日志不显示？

A: 检查：
1. 调试会话是否创建
2. WebSocket 是否连接
3. 后端日志是否有错误
