# 方案 43：截图标注编辑器二次设计方案

> **状态**：立项完成（2026-10-13，现状代码级调研 + 业界对标完成）；
> 待用户 review，实施排期另行指示。
> **背景**：0.7.5 用户反馈——截图标注中文字输入后在图上太小看不清、
> 无法调字号；要求对标业界截图工具对编辑栏做二次设计与优化
> （文字、划线等一系列操作，不限于这些，以提升使用体验为目标）。

## 一、背景与目标

**用户意图**：截图标注（方案 37 B2：画笔/箭头/矩形/文字 + 撤销 + 导出 PNG）
的编辑器体验向业界截图工具（Flameshot/Snipaste/ShareX 等）看齐——文字大小
可调（观看与导出都清晰）、划线等操作更顺手、编辑栏整体二次设计。

**成功标准**：
- 文字大小可调，且**显示与导出 PNG 观感一致**；默认值在 1080×2400 图上
  清晰可读（修复现「视觉≈5px」根因）；
- 线宽可调；覆盖业界共性集：滚轮调参、撤销/重做、键盘快捷键、复制到剪贴板；
- 已放置标注可选中/移动/删除（Snipaste/Flameshot 级核心体验）与文字二次编辑；
- 形状扩展：椭圆、荧光笔、序号气泡、马赛克（范围以本文档 §四 为准）；
- Chrome 实测验收全过（标注全操作 + 导出 PNG 校验）；双端门禁全绿。

**约束**：零新依赖（纯 canvas 自研）；Chrome-only（Clipboard API 等可用）；
不改变截图抓帧链路（仅编辑器内改造）；master 直做、禁 push。

## 二、现状调研（2026-10-13）

### 现状事实

- 组件 `frontend/src/components/stream/ScreenshotPreview.vue`（原生 canvas 2D，
  零依赖）。工具栏 4 工具（画笔/箭头/矩形/文字）+ 共享单色选择 + 撤销/清空/
  直接保存/导出 PNG；文字为行内输入行（先输入文案再点击放置）。
- **文字看不清根因**：`ctx.font` 字号硬编码 `20px`（`ScreenshotPreview.vue:312`），
  而 canvas 像素尺寸 = 截图原图尺寸（如 1080×2400）；显示时受弹窗 760px 与
  60vh 上限缩放（648/2400 ≈ 0.27），**视觉 ≈ 5px**；导出图中 20px 相对
  2400px 也极小。TextCmd 命令结构只存 `at/text/color` 无字号字段——
  **结构性不可调**。
- 线宽硬编码 4px（`:282`）；箭头头固定 14px/±30°（`:261-277`）——无粗细调节。
- 撤销仅「pop 栈」（`:397-402`），**无重做**；无键盘快捷键；无剪贴板复制；
  已放置文字无命中检测 → 不能移动/编辑；无椭圆/序号/荧光笔/马赛克。
- 坐标映射 `(client-rect)/rect × canvas 像素`（`:250-259`）正确，改造需保持。
- 每次打开弹窗会话归零（`:221-233`）；导出 `canvas.toBlob` + a.download
  （`:449-457`）。

### 业界对标（Flameshot / Snipaste / ShareX / Win11 截图 / QQ/微信）

| 维度 | 业界共性做法 | 本项目现状 |
|---|---|---|
| 字号/线宽 | 可调；**选中工具后滚轮即调**（Flameshot/Snipaste 最普遍的低成本交互） | 写死 20px/4px |
| 文字 | 拖动位置；Snipaste 拖角缩放/旋转；落定后二次编辑 | 落定不可动 |
| 形状 | 线/箭头/矩形/椭圆/序号气泡/荧光笔/马赛克/模糊（各家子集） | 仅 4 项 |
| 编辑栈 | undo + redo（Ctrl+Z / Ctrl+Shift+Z） | 仅 undo |
| 剪贴板 | Ctrl+C 复制到剪贴板（Flameshot/Snipaste/ShareX 全有） | 无 |
| 快捷键 | 数字键切工具、Esc 取消 | 无 |

## 三、设计

### §1 数据模型与根因修复（管道层）

- 命令模型参数化：`TextCmd` 增 `fontSize`；`PenCmd/ArrowCmd/RectCmd` 增
  `lineWidth`；新增 `EllipseCmd/HighlightCmd/NumberCmd/MosaicCmd`。
- **字号/线宽按「相对图宽百分比」存储**（如 `fontSize = width×0.045`、
  `lineWidth = width×0.0035`），渲染与导出同源换算——一次解决显示与导出
  观感一致、以及不同分辨率截图的一致性问题（根因修复）。
- 默认值以 1080 宽图为基准定标（默认字号 ≈48px@1080，视觉 ≈13px@60vh
  显示，清晰可读；线宽默认 ≈4px@1080 与现观感近）。
- undo/redo 双栈（新命令入栈时清空 redo）。

### §2 工具栏二次设计（分组）

```
[工具组] 画笔 箭头 矩形 椭圆 荧光笔 文字 序号 马赛克
[参数组] 颜色（色板 + 自定义）
        线宽滑块（随画笔/箭头/矩形/椭圆/荧光笔/马赛克显示）
        字号滑块（随文字/序号显示）
[操作组] 撤销 重做 | 清空 | 复制到剪贴板 | 直接保存 | 导出 PNG
```

- 参数组按当前工具显隐（单行分组浮层，对齐业界单行浮条风格）。
- 滚轮在画布上滚动 → 调当前工具参数（字号/线宽），对标 Flameshot/Snipaste。
- 快捷键：`1-8` 切工具、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Esc` 取消
  拖拽/取消选中、`Ctrl+C` 复制、`Ctrl+S` 导出。
- 兼容：既有行为（直接保存/导出 PNG 语义、坐标映射、会话归零）不变。

### §3 文字与已放置标注（核心体验升级）

- 文字 ghost 实时预览：鼠标移动显示落点与当前字号的半透明预览，点击落定
  （所见即所得，替代现「盲放」）。
- 命中检测与选中态：点击已放置标注（点距/包围盒命中）→ 高亮包围框 +
  拖动移动 + Delete 键删除；双击文字 → 重新编辑（复用输入行，字号可调）。
- 移动语义按命令类型区分：两点型（矩形/椭圆/箭头/马赛克）整体平移包围盒；
  画笔路径平移全部点；文字移动锚点。

### §4 新工具范围

- 椭圆、荧光笔（半透明粗线）、序号气泡（点击自动递增圆标，QQ 同款）；
- 马赛克（块状：drawImage 缩小再放大回贴局部，纯 canvas）；
- 模糊/OCR 自动打码本期不做（成本高/超范围）。

### §5 测试计划

- 命令模型单测：序列化结构、百分比→像素换算（渲染参数）、undo/redo 栈行为
  （含 redo 清空规则）、新命令类型渲染路径；
- 交互单测：工具切换、命中检测矩阵、快捷键绑定（Ctrl+Z / Ctrl+Shift+Z /
  Esc / 数字键）、ghost 预览状态、选中态进出；
- 剪贴板：mock `navigator.clipboard.write` + ClipboardItem 断言；
- 渲染一致性：mock canvas context 断言 `fontSize/lineWidth` 按图宽换算传参；
- 手动验收（Chrome）：1080×2400 真机截图字标注 → 导出 PNG 清晰度目检；
  滚轮调参、移动/删除/二次编辑、马赛克/序号全流程；既有功能回归。
