# 14 - 调试面板其他标签完善（Perf / Apps / Network）

> 在 Logcat 和 Shell 标签完成的基础上，完善剩余三个标签页，使调试面板达到生产可用。

## 目标

补齐 DebugPanel 中 Network、Perf、Apps 三个标签的完整实现，提供 Android 设备的：
- **Perf**：实时性能监控（CPU / 内存 / 帧率 / 当前 Activity）
- **Apps**：应用管理（列表 / 启动 / 停止 / 卸载 / 清数据 / 查看信息）
- **Network**：网络监控（连接状态 / 流量统计 / 活跃连接列表）

## 现状

| 标签 | 后端 API | 后端服务 | 前端组件 | 状态 |
|------|----------|----------|----------|------|
| Logcat | ✅ `/api/debug/sessions/{id}/logs` | ✅ DebugService | ✅ LogcatView.vue | 完成 |
| Shell | ✅ `/api/debug/sessions/{id}/shell` + WS | ✅ DebugService | ✅ ShellView.vue | 完成 |

| Apps | ✅ `/api/apps/{device_id}` RESTful | ✅ AppService | ✅ AppsView.vue | 完成 |
| Network | ✅ `/api/network/{device_id}/stats\|connections` | ✅ NetworkSampler | ✅ NetworkView.vue | 完成 |

## 模块 1：Perf 性能监控

### 1.1 后端：PerformanceSampler（数据采集）

**文件**：`backend/app/infrastructure/performance/sampler.py`（新建）

```python
@dataclass
class PerformanceMetrics:
    ts: float                 # Unix 时间戳
    cpu_percent: float        # CPU 使用率 0-100
    total_memory_mb: float    # 总内存 MB
    used_memory_mb: float     # 已用内存 MB
    fps: float | None         # 帧率（可选）
    jank_count: int           # 卡顿帧数
    current_activity: str     # 当前前台 Activity
    top_package: str          # 当前前台应用包名
```

**ADB 命令映射**：

| 指标 | ADB 命令 | 解析方式 |
|------|----------|----------|
| CPU | `dumpsys cpuinfo` | 解析 `CPU: X% user, Y% system, Z% idle` |
| 内存 | `cat /proc/meminfo` | 提取 MemTotal、MemAvailable |
| 帧率 | `dumpsys gfxinfo <pkg>` | 解析 Total frames rendered |
| 当前 Activity | `dumpsys activity activities \| grep mResumedActivity` | 正则提取组件名 |
| 前台包名 | `dumpsys activity top \| grep ACTIVITY` | 正则提取包名 |

**关键实现点**：
- 采样间隔默认 1 秒，可配置
- CPU 使用率通过两次 `/proc/stat` 采样差值计算（更准确）
- 错误处理：单个指标采集失败不影响其他指标
- 采样结果缓存在内存，最近 3600 条（1 小时）

### 1.2 后端：PerformanceService（服务层）

**文件**：`backend/app/application/performance_service.py`（新建）

```python
class PerformanceService:
    async def start_monitoring(self, device_id: str, interval: float = 1.0)
    async def stop_monitoring(self, device_id: str)
    async def get_metrics(self, device_id: str, limit: int = 100) -> list[dict]
    async def stream_metrics(self, device_id: str) -> AsyncIterator[PerformanceMetrics]
```

**关键设计**：
- 按 device_id 管理多个采样任务
- 内存环形缓冲：`dict[str, deque[PerformanceMetrics]]`，maxlen=3600
- `stream_metrics` 使用 `asyncio.Queue` 实现实时推送
- 设备断开时自动停止采样

## 模块 2：Apps 应用管理

### 2.1 后端：AppService（应用服务）

**文件**：`backend/app/application/app_service.py`（新建）

```python
@dataclass
class AppInfo:
    package_name: str
    version_name: str
    version_code: int
    install_time: str
    update_time: str
    apk_size_mb: float
    is_system: bool
    is_running: bool
    pid: int | None
    memory_kb: int | None

class AppService:
    def __init__(self, adb: AdbDriver):
        self.adb = adb
    
    async def list_apps(self, device_id: str, include_system: bool = False) -> list[AppInfo]
    async def get_app_info(self, device_id: str, package: str) -> AppInfo
    async def launch_app(self, device_id: str, package: str) -> bool
    async def stop_app(self, device_id: str, package: str) -> bool
    async def uninstall_app(self, device_id: str, package: str) -> bool
    async def clear_app_data(self, device_id: str, package: str) -> bool
    async def get_app_memory(self, device_id: str, package: str) -> int | None
```

**ADB 命令映射**：

| 操作 | ADB 命令 |
|------|----------|
| 列出应用 | `pm list packages -f -i -U` (第三方) 或加 `-s` (含系统) |
| 应用详情 | `dumpsys package <pkg>` |
| 启动应用 | `monkey -p <pkg> -c android.intent.category.LAUNCHER 1` |
| 强制停止 | `am force-stop <pkg>` |
| 卸载应用 | `pm uninstall <pkg>` |
| 清除数据 | `pm clear <pkg>` |
| 运行中应用 | `dumpsys activity processes \| grep <pkg>` |
| 应用内存 | `dumpsys meminfo <pkg>` |

## 模块 3：Network 网络监控

### 3.1 后端：NetworkSampler（网络采样）

**文件**：`backend/app/infrastructure/network/sampler.py`（新建）

```python
@dataclass
class NetworkStats:
    ts: float
    rx_bytes: int         # 接收字节数（累计）
    tx_bytes: int         # 发送字节数（累计）
    rx_rate_kbps: float   # 接收速率 KB/s
    tx_rate_kbps: float   # 发送速率 KB/s
    active_connections: int # 活跃连接数
    wifi_connected: bool
    wifi_ssid: str | None

@dataclass
class NetworkConnection:
    protocol: str         # tcp/udp
    local_addr: str
    local_port: int
    remote_addr: str
    remote_port: int
    state: str            # ESTABLISHED/LISTEN/CLOSE_WAIT/...
    pid: int | None
    program: str | None

class NetworkSampler:
    async def get_stats(self, device_id: str) -> NetworkStats
    async def get_connections(self, device_id: str) -> list[NetworkConnection]
    async def stream_stats(self, device_id: str) -> AsyncIterator[NetworkStats]
```

**ADB 命令映射**：

| 数据 | ADB 命令 | 解析 |
|------|----------|------|
| 流量统计 | `cat /proc/net/dev` | 提取 wlan0 的 rx_bytes/tx_bytes |
| 连接列表 | `cat /proc/net/tcp` + `cat /proc/net/tcp6` | 解析 hex 地址 |
| WiFi 状态 | `dumpsys wifi \| grep mWifiInfo` | 解析 SSID 和状态 |
| 网络接口 | `ip addr show` | 提取 IP 地址 |

## 技术风险

| 风险 | 影响 | 概率 | 应对 |
|------|------|------|------|
| ADB 命令在不同 Android 版本输出格式不同 | 中 | 高 | 多设备测试 + 正则容错 |
| ECharts 大数据量渲染卡顿 | 中 | 中 | 限制数据点数（60 个）+ 降采样 |
| 网络命令需要 root 权限 | 高 | 中 | 使用 `/proc/net/` 非 root 可读接口 |
| 应用列表加载慢（大量应用） | 中 | 中 | 分页加载 + 缓存 |
