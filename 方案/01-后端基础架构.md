### 2. 配置管理

**文件**：`config/settings.py`

**实现要点**：
- 使用 `pydantic-settings` 定义配置类
- 支持 YAML 文件 + 环境变量
- 配置优先级：env > YAML > 默认值
- 配置分层：app / server / database / adb / stream / debug / security

**示例**：
```python
class Settings(BaseSettings):
    app: AppConfig
    server: ServerConfig
    database: DatabaseConfig
    # ...
```

### 3. 依赖注入

**文件**：`backend/app/deps.py`

**实现要点**：
- 使用 `@lru_cache()` 实现单例
- 工厂函数创建服务实例
- 依赖倒置：服务依赖 Protocol，不依赖实现

**示例**：
```python
@lru_cache()
def get_adb_driver() -> AdbDriver:
    return AdbCliDriver()

def get_device_service() -> DeviceService:
    return DeviceService(
        adb=get_adb_driver(),
        repo=get_device_repository(),
    )
```

### 4. 结构化日志

**文件**：`backend/app/core/logging.py`

**实现要点**：
- 使用 `structlog` 替代标准 logging
- 开发环境：Console 渲染（彩色）
- 生产环境：JSON 渲染（便于收集）
- 上下文变量（contextvars）支持

**示例**：
```python
logger.info("listing_devices", device_count=10)
# 输出: 2026-09-08 12:00:00 [info] listing_devices device_count=10
```

### 5. 异常处理

**文件**：`backend/app/core/exceptions.py`

**实现要点**：
- 自定义异常基类 `OpenScrcpyException`
- 统一错误响应格式
- 异常处理器注册

**示例**：
```python
class DeviceNotFoundError(OpenScrcpyException):
    def __init__(self, device_id: str):
        super().__init__(f"Device not found: {device_id}", code="DEVICE_NOT_FOUND")
```

### 6. 生命周期管理

**文件**：`backend/app/lifecycle.py`

**实现要点**：
- 使用 `@asynccontextmanager` 管理启动/关闭
- 启动时初始化数据库、日志、遥测
- 关闭时清理资源

**示例**：
```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup
    setup_logging()
    await init_db()
    yield
    # Shutdown
    cleanup()
```
