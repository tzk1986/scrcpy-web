## 一、背景与目标

1. **标注缩放**：方案 43 编辑器已支持选中拖动移位与 Delete 删除，但**几何尺寸与
   字号/线宽只能在画前经滑块设定，画后不可改**——标错了大小只能删除重画。
   用户要求 PS 自由变换手感：选中 → 拖包围盒手柄缩放，几何与字号/线宽联动，
   落定可撤销。
2. **配对码**：无线连接现状仅 `adb connect` 单路（传统「网络 ADB 调试」，端口
   固定 5555）。Android 11+ 官方「无线调试」为随机端口 + 6 位配对码，需
   `adb pair` → `adb connect` 两步，后端无 pair 原语（2026-10-13 grep 核实，
   2026-10-15 复核仍零命中）。目标设备 .18 即 Android 11，用户实操必然遇到。
3. **参数手册**：方案 45 设置页 7 参数 + 设备级覆盖，用户不清楚「改了会怎样、
   什么情况调大调小」。目标：设置页可达的说明手册页，逐参数给出含义 / 调大效果
   与场景 / 调小效果与场景 / 建议区间 / 生效时机，读后可返回设置。

## 二、现状调研（2026-10-15）

### 2.1 标注编辑器（方案 43 交付形态）

- `annotationModel.ts`：**命令式可重放模型**——8 类命令
  （pen/arrow/rect/ellipse/highlight/text/number/mosaic），几何为 `Point`
  （points / from,to / at），参数 `fontSize`/`lineWidth` 均为**相对图宽比例**，
  渲染经 `fontPx/linePx ×canvasWidth` 换算（显示与导出同源）。
  纯函数已备：`cmdBBox`（含 text 经 measure 回调）、`hitTest`（顶向下首个命中）、
  `translateCmd`（原地平移）、`drawCmd`（全类型渲染，mosaic 实时重采样底图）。
- `ScreenshotPreview.vue`：`commands` 数组即渲染源（全量重放）；选中画虚线包围盒
  （`cmdBBox` 外扩）；pointerdown 命中 → `moveState` 拖动实时 `translateCmd`；
  双击 text/number 进编辑态；Delete 删除选中；undo/redo **以命令为步骤**
  （undo=弹栈入 redoStack；移位原地 mutate、**不产生 undo 步骤**——撤销移位
  等于撤销整条标注）；滚轮按工具组调字号/线宽滑块；`FONT/LINE_RATIO_MIN/MAX`
  已有 clamp 常量。
- 结论：缩放 = 新增 `transformCmd` 仿射 + 手柄渲染/命中，模型与渲染管线**零改动**；
  「缩放（及移位）可逐步撤销」需把 undo 栈升级为操作历史——用户拍板**一并升级**。

### 2.2 adb 配对链路（官方语义核实，2026-10-15）

- 语法：`pair HOST[:PORT] [PAIRING CODE]`——**非交互形态存在**（码作第二参），
  适合服务端代发；交互式仅 tty 场景。platform-tools ≥31 才有 `pair` 子命令
  （老 adb 报 `command 'pair' not found`）；exe 内置 adb 1.0.41（新于 31），
  开发机 adb 版本不一 → 该报错须映射专门文案。
- **配对端口 ≠ 连接端口**：配对码弹窗给「配对端口」，连的是主页面「IP 地址和端口」
  的**另一个随机端口**；两者皆随无线调试开关/重启变化。
- 信任持久：配对关系存于**设备侧**（配对列表），宿主凭 `~/.android/adbkey` 私钥
  连接；已配对后重连只需 `adb connect ip:新端口`，**无需重新配对**
  （Android 16 部分 OEM 收紧为重启后需重配对——手册提示即可）。
- 现状代码：`cli.py` `_run` 通用 spawn（超时 + CREATE_NO_WINDOW 全树门禁罩着）；
  `connect_tcp` 有 `probe_tcp` 预检先例（不可达快速失败）；成功判定字符串匹配。
  `/api/devices/connect` 为 query 参数形态。无 pair 原语。
- **网段扫描边界**：无线调试配对/连接端口随机，扫描不可达（仅传统 5555 可扫），
  配对入口走手动 IP 输入，文档明示。

### 2.3 设置页与手册介质

- 设置页 `/settings` 四卡片（运行参数/生效参数/运行环境/设备级覆盖）；
  参数键：串流 `max_size / bit_rate / fps / codec / adaptive_bitrate`、
  录屏 `bit_rate / time_limit`；生效时机：串流=下次连接、录屏=每次开始录屏时读取；
  来源徽标：出厂默认/用户设置/环境覆盖。
- 路由现 5 页；手册介质裁定：**前端静态路由页**（内容=结构化 TS 数据 + 模板渲染），
  零新依赖、打包版天然可用、无后端面；md 解析器不引入。
- 返回导航复用 0.7.9 智能范式：上一跳恰为目标页 → `history.back()` 不垫栈，
  否则回落 `push`。

## 三、设计

### A. 标注拖拽缩放

#### A1 纯函数层（`annotationModel.ts` 追加，T1）

- `resizeHandles(bbox)` → 8 个手柄点（四角 nw/ne/sw/se + 四边中点 n/s/w/e）。
- `hitHandle(point, handles, canvasWidth)` → 手柄 id | null；命中半径
  `max(6, canvasWidth × 0.006)`（顶向下首个，与 hitTest 同序风格）。
- `transformCmd(cmd, bbox, sx, sy, anchor)`：以 anchor（拖出时固定不动的对角点）
  为中心对几何做仿射：
  - pen/highlight：逐点仿射；arrow/rect/ellipse/mosaic：from/to 两点；
    text/number：at 点仿射。
  - 参数联动：`fontSize *= min(sx, sy)`（非等比时取较小方向，防文字过大出框），
    `lineWidth *= (sx + sy) / 2`；结果 clamp 回 `*_RATIO_MIN/MAX`。
  - `sx/sy` 为**有向倍率**：允许拖过对角产生负值 → from/to 交叉（几何自然翻转），
    参数取 `|s|`；下限 `0.02`（防除零/压扁为 0）。
- 纯函数不动既有导出签名；text 的 measure 口径不变（bbox 随 fontSize 重算，
  拖后下一帧手柄位置自然更新）。

#### A2 操作历史（T2，undo 语义升级——拍板 R1）

- `commands` 保留为渲染源；新增 `history: HistoryStep[]` 与 `redoHistory`：
  ```
  HistoryStep =
    | { kind: 'add'; cmd }                       // 新绘/放置文字序号
    | { kind: 'delete'; cmd; index }             // Delete 键删除
    | { kind: 'transform'; index; before; after } // 移位/缩放落定（深拷贝快照）
    | { kind: 'edit-text'; index; before; after } // 双击改文字
    | { kind: 'clear'; snapshot }                 // 清空全部（一步可撤销）
  ```
- undo：按末步反向回放（add→移除；delete→原位插回；transform/edit-text→还原
  before 快照；clear→还原快照数组）。redo 对称；落新步清 redoHistory。
- 兼容性：`getCommands`/`getAnnotationCount` 等 expose 保持；方案 43 既有
  undo/redo 测试**适配新语义**（add 步骤行为等价旧「弹栈」；断言口径改 history）。
- 移位纳入 transform 步：拖动期间实时 mutate（渲染照旧），**pointerup 落定才
  产生一步**（before=pointerdown 快照）。

#### A3 手柄交互（T3）

- 选中命令：虚线包围盒（现状）+ 8 手柄方块（canvas 绘制，半径随图宽比例）。
- pointerdown 命中序：**手柄 > 已有命令 > 空白**；命中手柄 →
  `resizeState { index, handle, bbox0, anchor, before快照 }`，pointermove 实时
  `transformCmd` 预览，pointerup 落定为一步 transform。
- 等比约束（Shift，拍板 R3）：sx 与 sy 取拖出方向投影的较大等比值，锚点不变；
  角手柄等比、边手柄 Shift 时沿对角等比。
- 光标：按手柄映射 `nwse/ns/nesw/ew-resize`；手柄命中区外维持现状光标。
- Delete/Escape/滚轮行为不变；mosaic 缩放=重采样区变化（drawCmd 天然正确）；
  导出/下载走同一 commands 重放，**导出零改动即含缩放结果**。

### B. 无线调试配对

#### B1 后端（T4）

- `ports.py`：`async def pair_tcp(self, ip: str, port: int, code: str) -> None`。
- `cli.py` `AdbCliDriver.pair_tcp`：
  1. `probe_tcp(ip, port, probe_timeout)` 预检（不可达 → DeviceUnreachableError，
     与 connect 同语义）；
  2. `self._run("pair", f"{ip}:{port}", code)`；
  3. 成功判定 `"successfully paired" in output.lower()`；
  4. 失败分类抛 `AdbError`（携带可辨信息）：
     输出含 `wrong pairing code`/`code` 类 → 配对码错误；
     含 `command 'pair' not found`/`unknown command` → adb 版本过旧（提示
     「需 platform-tools ≥31」）；
     其他（超时/拒绝）→ 配对请求失败（提示检查配对弹窗是否仍打开、端口是否最新）。
- `devices.py`：`POST /api/devices/pair?ip=&port=&code=`；
  校验（422，沿用 settings 端点 pydantic 白名单风格）：ip IPv4、port 1-65535、
  code 恰 6 位数字字符串（**前导零保留 → 字符串入参**）；
  成功返回 `{"success": true, "paired": "ip:port"}`；错误沿用结构化
  `{"error":{code,message}}` 先例（如 `PAIR_FAILED`）。
- 连接复用 `/api/devices/connect`；**不新增配对记录存储**（信任在设备侧 +
  adbkey，重启/换端口走 connect 即可）。

#### B2 前端（T5，拍板 R2：添加设备对话框加页签）

- `Dashboard.vue` 添加设备对话框 → `el-tabs`：
  - 页签 1「网络 ADB（传统）」：现表单**零改动**；
  - 页签 2「无线调试配对（Android 11+）」两步：
    步骤 1：IP + 配对端口 + 6 位配对码 →「配对」→ 成功 toast
    「配对成功，请在手机『无线调试』主页面查看连接端口」并切到步骤 2；
    失败按 error.code 映射中文文案回显（含 adb 过旧指引）。
    步骤 2：端口输入 →「连接」→ 走既有 `store.connectDevice(ip, port)` 链路
    （成功后关对话框、列表重拉，同现状语义）。
- `api.ts` 增 `pairDevice(ip, port, code)`；测试桩同步。
- 页签底部固定说明区：配对码弹窗位置 / 端口会变、重连只需步骤 2 /
  Android 16 部分机型重启后需重新配对。

### C. 参数说明手册

#### C1 内容数据（T6）

- 新文件 `frontend/src/views/settingsHelpData.ts`：结构化数组——每参数
  `{ key, group, name, meaning, larger: {effect, scenario}, smaller: {effect,
  scenario}, range, when_effective }`；覆盖串流 5 + 录屏 2 + 设备级覆盖 +
  生效时机/来源徽标 + 与网段扫描/配对手册互引（可选）。示例口径：
  - `max_size`：调大→更清晰、解码/带宽压力↑（强机+好网）；调小→省带宽更流畅
    （弱设备/远程卡顿/花屏→720 或 540）；范围 0~65535（0=不限）。
  - `bit_rate`：调大→画质细节↑流量↑；调小→省流量易糊（4M 常用，弱网 2M）。
  - `fps`：调大 60→动画/游戏顺滑、解码压力↑；30 一般调试够用；低→省资源。
  - `codec`：h265 同画质省约一半码率，但需设备（Android 10+）+ 浏览器双支持，
    不支持回落 h264 或禁选；h264 兼容性最好。
  - `adaptive_bitrate`：开→网络差自动降码率保流畅；关→恒定码率画质稳定可预期。
  - 录屏 `bit_rate`：只影响录屏产物（与串流独立）；调大文件更大更清晰。
  - `time_limit`：0=不限时（靠手动停 + 磁盘双限清理兜底）；调小→单文件小、
    需手动续录；与方案 42 双限清理联动说明。
  - 设备级覆盖：只填想改的键？——实现为全节提交，文案说明「保存后该设备
    下次连接生效；清除回到全局」。
- **单一来源**：文案只存 `settingsHelpData.ts`；`docs/` 不留副本（避免漂移），
  docs/经验记录.md 如涉参数调整直接引本页。

#### C2 页面与入口（T6）

- 新路由 `/settings/help`（SettingsHelp.vue）：分组渲染数据（串流/录屏/覆盖/
  通用说明），锚点 id=`<参数键>`；无 device query 语义（纯文档页）。
- 设置页入口：页头「参数说明手册」链接 + 各参数行「?」小图标 →
  `/settings/help#<键>`；手册页「← 返回设置」按钮——**智能返回范式**

- App.vue 菜单不加项（文档页从设置进入，避免菜单噪声）。
