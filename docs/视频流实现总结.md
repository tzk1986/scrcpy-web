## 当前问题

服务器在协议握手后立即关闭连接，没有发送视频数据。可能原因：

1. **编码器初始化失败** - 设备可能不支持请求的编码参数
2. **协议不完全匹配** - 可能还有未实现的协议步骤
3. **server 版本兼容性** - v2.4 可能与 Android 7.1.2 设备不完全兼容
4. **缺少必要参数** - 可能需要额外的编码器配置参数

## 下一步建议

### 方案 A: 使用 py-scrcpy-client
安装依赖并直接使用 py-scrcpy-client：
```bash
pip install adbutils opencv-python numpy
pip install scrcpy-client
```
然后修改代码使用 py-scrcpy-client 的 Client 类。

### 方案 B: 手动调试 server
使用 adb 手动运行 server 并查看详细日志：
```bash
adb shell CLASSPATH=/data/local/tmp/scrcpy-server.jar \
    app_process / com.genymobile.scrcpy.Server 2.4 \
    tunnel_forward=true video=true audio=false control=false \
    log_level=debug max_size=1080 max_fps=30 video_bit_rate=4000000
```

### 方案 C: 检查设备编码器支持
```bash
adb shell dumpsys media.codec | grep -i encoder
```

### 方案 D: 尝试不同的 server 版本
测试 v2.0, v2.1, v2.2 等版本，看哪个与设备兼容。
