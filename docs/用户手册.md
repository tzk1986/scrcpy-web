# OpenScrcpy 用户手册

> 适用版本：v0.7.10
> 运行平台：Windows 10/11
> 浏览器：Chrome（最新两个稳定版）

## 一、产品简介

OpenScrcpy 是一个基于浏览器的 Android 设备投屏与调试工具。它通过 ADB（Android Debug Bridge）连接
Android 设备，在网页中实时显示设备画面并支持鼠标/触摸操控，同时提供日志查看、远程 Shell、应用管理、
性能监控、网络监控等一整套调试能力。客户端零安装：只需在电脑上启动本工具，用 Chrome 打开网页即可使用，
支持同时接入多台设备。

主要能力：

- 设备管理：查看已连接设备列表、通过 TCP/IP 添加设备、断开设备，列表实时更新
- 实时投屏：H.264 视频流（约 30 FPS），画面异常时自动回退到截图模式（约 0.7 FPS）
- 输入控制：鼠标点击、滑动、长按，以及返回/主页/多任务/菜单导航键
- 应用管理：查看应用列表与详情，启动、停止、清除数据、卸载应用
- 远程 Shell：基于 PTY 的交互式终端，支持 Tab 补全、命令历史、交互式命令
- 日志查看：实时 logcat、级别过滤、关键词搜索、导出 JSON/CSV、点击复制
- 性能监控：CPU、内存、帧率、前台应用，实时曲线图
- 网络监控：WiFi 状态、收发速率、流量曲线、活跃连接列表
- 命令面板：Ctrl+K 全局快捷命令（切换页面、切换调试标签、全屏等）
- 参数设置：独立设置页可视化配置串流/录屏参数，支持设备级参数覆盖、生效值来源标注、
  运行环境信息与检查更新

## 二、环境准备

### 2.1 开启设备 USB 调试

1. 在 Android 设备上进入「设置」-「关于手机」，连续点击「版本号」7 次，启用开发者选项
2. 进入「设置」-「系统」-「开发者选项」，打开「USB 调试」
3. 用数据线将设备连接到电脑，设备屏幕上会弹出「允许 USB 调试吗？」，勾选「始终允许」并点击「允许」

### 2.2 USB 连接

设备通过 USB 连接并授权后，无需其他操作，打开工具网页即可在设备列表中看到它。

### 2.3 无线（TCP/IP）连接

无线连接需要设备先开启 TCP/IP 调试模式，常用做法如下：

1. 先用 USB 连接设备并授权（见 2.1）
2. 在电脑上执行 `adb tcpip 5555`，让设备在 5555 端口监听调试连接
3. 拔掉数据线，确保电脑与设备处于同一局域网
4. 在工具网页中点击「添加设备」，填入设备的 IP 地址与端口（默认 5555），点击「连接」

说明：

- 本工具自带 adb（位于项目的 `tools` 目录，若存在则优先使用），也可以使用系统中已安装的 adb
- 设备 IP 可在「设置」-「关于手机」-「状态信息」中查看
- Android 11 及以上系统的「无线调试」功能分配的端口不一定是 5555，请以设备上显示的端口为准

## 三、启动与访问

当前版本提供绿色免安装 exe（Windows 绿色版，推荐，使用与故障排查见随包《Windows exe 发布说明》）与源码运行两种方式。以下为源码运行步骤。

### 3.1 环境要求

- Windows 10/11
- Python 3.11 及以上
- Node.js 20 及以上
- Chrome 浏览器（最新两个稳定版）

### 3.2 安装依赖（仅首次）

在项目根目录执行：

```bash
pip install -e ".[dev]"
cd frontend && npm ci --legacy-peer-deps
```

### 3.3 启动

打开两个终端窗口，在项目根目录分别执行：

```bash
# 终端 1：启动后端（默认监听 8765 端口）
python run_server.py

# 终端 2：启动前端开发服务器（监听 8080 端口，自动把 /api 和 /ws 转发到后端）
cd frontend && npm run dev
```

两个窗口都保持运行，不要关闭。

### 3.4 访问

用 Chrome 打开：

- 工具页面：<http://localhost:8080>
- 后端健康检查：<http://localhost:8765/health>
- 后端 API 文档：<http://localhost:8765/docs>

停止服务：在对应终端窗口按 Ctrl+C。

## 四、界面导航

页面结构如下：

```
顶部导航栏：OpenScrcpy 标题 + 菜单（Dashboard / 录屏 / 设置）
    │
    ├─ 仪表盘（设备列表页，路径 /）
    │      └─ 点击设备的「连接」按钮
    │
    ├─ 设置页（路径 /settings）
    │      └─ 运行参数 / 生效参数 / 运行环境 / 设备级参数覆盖
    │
    ├─ 录屏页（路径 /recordings）
    │      └─ 历史录屏列表 / 播放 / 下载 / 导出 webm / 删除
    │
    └─ 设备详情页（路径 /device/<设备ID>）
           ├─ 左侧/上方：投屏画面 + 导航键 + 状态栏
           └─ 右侧/下方：调试面板（Logcat / Shell / Network / Perf / Apps 五个标签页）
```

- 仪表盘：设备列表与「添加设备」入口，点击任意设备的「连接」进入设备详情页
- 设备详情页：实时画面与全部调试功能；顶部「断开」按钮关闭会话并返回设备列表，
  「设置」按钮带当前设备名跳转设置页（自动聚焦该设备的覆盖表单）
- 设置页：顶部菜单「设置」进入，配置串流/录屏参数、查看生效来源与运行环境（见 5.14）
- 录屏页：顶部菜单「录屏」进入，集中处理历史录屏产物（列表/播放/下载/导出 webm/删除，见 5.15）
- 调试面板：五个标签页，可停靠在页面右侧或底部，可在两者之间切换并拖拽调整大小

## 五、功能操作指南

### 5.1 设备管理（仪表盘）

设备列表以表格展示，包含列：勾选、设备ID（设置了备注的显示「备注 + 序列号」两行）、
屏幕缩略图（4:3 外框自适应裁切，点击可放大查看，悬停显示快照时间）、型号、系统版本、
分辨率、电量、状态（在线 / 无响应）、操作。表格上方提供搜索框与每行「备注」按钮（见下）。

- 添加设备：点击右上角「添加设备」，在弹窗中填写 IP 地址（如 `192.168.1.100`）与端口
  （默认 5555，范围 1-65535），点击「连接」。连接成功后弹窗关闭并提示「已连接到 <IP>:<端口>」，
  设备会自动出现在列表中
- 刷新：点击「刷新」按钮重新扫描设备列表
- 连接：点击某行的「连接」按钮，进入该设备的详情页开始投屏与调试
- 断开：仅通过 TCP/IP 连接的设备（设备ID 形如 `IP` 或 `IP:端口`）显示「断开」按钮；
  点击后断开该设备的 TCP/IP 连接并从列表移除
- 缩略图自动加载：在线设备的屏幕缩略图随列表自动加载，无需点击；加载失败的设备不会
  自动重试，可点击「加载失败（点击重试）」或扫平全表用「刷新缩略图」强制重拉
- 批量断开：勾选一台或多台 TCP 设备后出现工具条，点击「批量断开」并确认后逐台断开；
  「取消选择」清空勾选（USB 设备不可勾选，没有 TCP 断开语义）
- 备注（设备别名）：点击行内「备注」按钮，在弹窗中为设备起一个好记的名字（不超过 64
  字符），确认后设备ID 列优先显示备注、下行灰字保留序列号。备注保存在服务端用户配置中，
  断线重连、刷新页面后仍在；不校验设备是否在线。留空提交即清除备注，显示回落序列号
- 搜索：表格上方搜索框按「备注 / 型号 / 设备ID」三个字段本地过滤（子串匹配、不区分
  大小写），输入即筛选，清空恢复全量
- 网段扫描：在「扫描并连接」左侧输入目标并点击扫描。目标支持三种写法（点击输入框旁
  「?」可查看说明）：
  - 单个 IP：`192.168.8.18`（只扫这一台）
  - 网段（CIDR）：`192.168.8.0/24`（支持 /22 到 /32）
  - 起止区间：`192.168.8.10-100`（只扫 .10 到 .100；也支持完整写法如
    `192.168.8.10-192.168.9.20`）
  - 右侧数字框为 ADB 端口（默认 5555）；勾选「仅扫描不连接」只探测不连接
- 扫描结果：摘要下方列出全部开放主机，按状态分「已连接 / 连接失败 / 未连接」；
  「仅扫描不连接」时结果条目可直接点击「连接」（端口取扫描时填写的值），
  失败条目可点击「重试」单台重连
- 无响应设备：设备网络在线但 ADB 命令持续超时（如设备负载过高、adbd 卡死）时，状态列
  显示红色「无响应」标签（替代原先的「在线」），整行文字置灰（型号/版本等为缓存值），
  「连接」按钮变为描边弱化样式。此时截图与投屏大概率失败（黑屏）。悬停「无响应」标签
  可查看处理指引；设备恢复后点击「刷新」即回落「在线」
- 实时更新：页面会自动接收设备连接/断开事件并更新列表，无需手动刷新
- 空列表提示：未检测到设备时页面会提示通过 USB 连接设备，或点击「添加设备」通过 TCP/IP 连接

### 5.2 投屏与输入控制

进入设备详情页后，投屏自动开始。画面区下方为控制栏，包含导航键与状态信息。

输入操作（在画面上操作）：

- 点击：短按（约 0.5 秒以内）且基本不移动，等效于点按设备屏幕对应位置
- 滑动：按住并拖动一段距离（约 20 像素以上）后松开，等效于设备上的滑动操作
- 长按：按住不动约 0.5 秒，触发设备上的长按
- 支持触摸屏设备（单指），操作方式与鼠标一致

状态栏字段说明：

- 模式：`h264` 为 H.264 实时视频流；`screenshot` 为截图回退模式
- FPS：实测帧率；帧：累计接收帧数；丢帧：h264 模式下的丢帧计数
- 状态：连接中 / 配置中 / 直播中 / 错误 / 已停止（连接出错时画面中央会显示错误信息与「重新连接」按钮）

H.264 与截图模式：

- 正常情况使用 H.264 视频流（约 30 FPS）
- 当浏览器不支持 H.264 解码（WebCodecs）或码流异常（解码报错、画面冻结超过约 3 秒、
  连接后长时间没有画面）时，会自动回退到截图模式
- 截图模式约 0.7 FPS（每 1.5 秒刷新一帧），画面左上角显示「只读预览 · 输入不可用」徽标，
  此模式下点击/滑动不会发送到设备
- 码流恢复后会自动切回 H.264 模式，无需手动操作

提示：

- 浏览器标签页切到后台时，画面继续接收，但帧率上报与输入操作会暂停以降低负载；切回前台自动恢复
- 自适应码率调整（网络变差时自动降档）会造成切档瞬间 1-3 秒黑屏，属正常现象

### 5.3 导航键

画面下方的按钮依次为：

- 返回（←）：等效于设备的返回键
- 主页（●）：等效于设备的主页键
- 多任务（■）：打开最近任务列表
- 菜单（≡）：等效于设备的菜单键

### 5.4 屏幕工具（录屏 / 截图标注）

设备详情页右上角提供「截图」与「录屏」按钮。

**录屏**：

- 点「录屏」开始，设备端即开始录制屏幕（单次最长 60 秒自动停止并自动拉回录像），按钮处出现红点与计时
- 点「停止」结束录制，工具自动把视频从设备拉取到本机，面板显示「已保存（约 X MB）」一行提示，并提供「查看录屏」与「重新录制」按钮
- 点「查看录屏」跳转到「录屏」页并自动过滤出该设备的产物（见 5.15）；点「重新录制」可直接再录一段，无需刷新页面
- 同一台设备同时只允许一路录屏；若服务端已有进行中的录制会话，再次点「录屏」会收到互斥提示
- 部分低端设备不支持高分辨率录屏，会自动降为 256x144 分辨率重试一次（画面较模糊属正常现象）
- 录制中离开设备页无需点停止：录满 60 秒后服务端自动收尾拉回，重进页面即可看到「已保存」提示
- 录像文件属暂存：优雅退出服务（含界面退出）会清空 `data/recordings/` 目录；强杀/崩溃遗留的文件在下次服务启动时自动清扫（保留策略详见 5.15）

**截图标注**：

- 点「截图」截取当前画面并弹出预览窗口
- 工具栏提供 8 种标注工具：画笔、箭头、矩形、椭圆、荧光笔、文字、序号、马赛克；颜色从预设色板或自定义色中选取（马赛克无颜色参数）；荧光笔为半透明粗线
- 文字工具先输入内容、点「确认」后点击画布放置（放置前悬停可见半透明预览）；序号点击即落编号（自动递增，删除中间不重号）；马赛克拖出区域后以块状覆盖
- 画布滚轮或参数行滑块可调当前工具的字号线宽（对新添加的标注生效；参数行按当前工具显示对应滑块）
- 支持撤销（按钮或 Ctrl+Z）与重做（快捷键 Ctrl+Shift+Z）；点「清空」一键清除全部标注
- 点击已放置标注可选中并拖动位置（矩形/椭圆点击图形内部任意处即可选中，不必压在边框上；
  图形相互重叠时选中最上层的那个）；按 Delete/Backspace 删除选中标注；双击文字可原地修改文案
- 点「复制」或按 Ctrl+C 把带标注图片复制到剪贴板；点「导出 PNG」保存带标注的图片；点「直接保存」则下载未标注的原图
- 快捷键：1-8 切换工具（按工具栏顺序）、Ctrl+Z 撤销、Ctrl+Shift+Z 重做、Ctrl+C 复制、Ctrl+S 导出、Esc 取消选中/退出编辑（文字输入框聚焦时数字键与组合快捷键不生效，Esc 除外）

### 5.5 文件管理（设备详情「文件」按钮）

设备详情页右上角点「文件」进入该设备的文件管理页（独立页面，工具栏「返回设备」可回详情页）。

- 浏览：默认打开 `/sdcard`；点击目录名逐级进入，面包屑（含 `..`）可逐级返回。列表显示
  名称、大小、修改时间、权限，符号链接会显示指向目标。浏览为全盘可读（如 `/proc`、`/system`）
- 上传：点「上传」选择一个或多个本地文件，逐个上传到当前目录；写操作仅允许 `/sdcard`
  与 `/data/local/tmp` 两个区域，其余路径会被拒绝
- 下载：勾选文件后点「下载」——选一个下载原文件，选多个打包为 zip（命名形如
  `首个文件名_etc.zip`）下载；目录不可下载
- 重命名：勾选单个条目后点「重命名」，弹窗内输入新名称（非法名称会被拒绝）
- 删除：勾选一个或多个条目后点「删除」，弹窗二次确认（删除目录会提示将递归删除其中
  全部内容）；执行后按条目汇总成功/失败结果
- 传输进度：传输时工具栏下方显示进度行——HTTP 段显示真实百分比，设备端读写段（adb）
  显示条纹动画（该段无法精确细分进度，不伪造百分比）
- 传输互斥：同一台设备同时只允许一个传输任务，进行中再次发起会提示稍后再试
- 设备离线时页面整体提示「设备离线，无法管理文件」并禁用全部操作；路径无权限提示
  「该路径不可访问」，目录不存在显示错误与「重试」

### 5.6 应用管理（Apps 标签）

- 搜索：顶部搜索框按包名过滤（不区分大小写），输入即筛选
- 筛选：下拉框可切换「用户应用 / 全部应用 / 系统应用 / 运行中」，默认「用户应用」
- 刷新：点击「刷新」重新拉取应用列表；底部状态栏显示应用总数与运行中数量
- 启动：对未运行的应用点击「启动」，成功后提示「已启动 <包名>」
- 停止：对运行中的应用点击「停止」，强制停止该应用
- 更多菜单：点击「更多」展开
  - 清除数据：二次确认后清除应用数据（不可恢复）
  - 卸载：二次确认后卸载应用；系统应用不可卸载（按钮置灰）
- 应用详情：点击列表任意一行打开详情对话框，显示基本信息（包名、版本、版本代码、状态、类型、
  安装/更新时间）与运行信息（APK 大小、内存占用、进程 ID），并在对话框内提供启动/停止、
  清除数据、卸载、刷新信息按钮
- 运行时：详情对话框打开时自动查询一次运行时状态，展示当前栈 Activity、Resumed Activity 卡片
  与 Service 清单（名称/状态）；点「刷新运行时」按需重新查询；部分机型解析缺失的字段会给出
  相应提示，不影响其余信息展示

### 5.7 远程 Shell（Shell 标签）

基于 PTY 的交互式终端（固定 80x24），支持两种输入方式：

- 终端直接输入：点击终端区域后可直接输入，支持交互式命令（如 `top`、`vi`）、Tab 补全；
  终端内按键会实时透传到设备
- 底部输入框：输入命令后按 Enter 或点击「发送」执行；↑/↓ 浏览命令历史（保留最近 50 条）；
  按 Tab 向设备发送补全；输入框提示文字为「输入命令，Enter 发送，↑↓ 切换历史，Tab 补全...」

终端区域显示设备命令行的实时输出，可用鼠标选中文本进行复制。

### 5.8 日志查看（Logcat 标签）

默认处于暂停状态（顶部显示「日志录制已暂停」提示条），按以下步骤使用：

1. 点击左上角「开始」按钮，开始接收实时日志（按钮变为「暂停」，右侧出现 LIVE 指示）
2. 级别过滤：下拉框选择 Verbose / Debug / Info / Warning / Error / Fatal（可清空）
3. 关键词搜索：搜索框匹配日志 Tag 或消息内容（不区分大小写）
4. 自动滚动：默认开启；新日志到达时自动滚到底部，可手动关闭
5. 点击任意一条日志：复制该条日志到剪贴板
6. 刷新：从后端重新拉取日志；统计区显示「共 N 条」或「显示 X / N 条」，并显示数据库大小「DB: x MB」
7. 导出：点击「导出」选择「导出 JSON」或「导出 CSV」，浏览器下载文件（文件名形如
   `logs_<会话ID>.json` / `.csv`）；导出内容会应用当前的级别与搜索过滤条件
8. 清空：仅清空界面中显示的日志列表
9. 清理：清除该会话在后端数据库中的日志并刷新列表

再次点击「暂停」可停止接收新日志，已收到的日志仍保留可搜索。

### 5.9 性能监控（Perf 标签）

页面每约 1 秒更新一次，保留最近 60 秒的数据：

- CPU 使用率：百分比卡片与进度条（超过 80% 时数字变黄），下方为 CPU 历史曲线
- 内存使用：已用 / 总内存（MB）与进度条，下方为内存历史曲线
- 帧率：当前 FPS（低于 30 时数字变黄），并显示卡顿帧数（按采样窗口统计）
- 当前应用：前台应用包名与当前 Activity
- 进程 CPU Top 8：展示 CPU 合计占用最高的 8 个进程（按占用从高到低排列）
- 电池：展示电池温度（摄氏直显）、电压（毫伏）与健康状态；设备暂未提供的项目会自动隐藏
- 底部状态栏：LIVE 指示与「数据点: N / 60」

### 5.10 网络监控（Network 标签）

数据每约 2 秒自动刷新，保留最近 60 个数据点：

- WiFi 状态栏：显示当前 SSID 与「已连接 / 断开」标签
- 指标卡片：接收速率与累计接收量、发送速率与累计发送量、活跃连接数
- 流量曲线：接收/发送速率（KB/s）随时间变化的折线图
- 活跃连接列表：显示每条连接（TCP/UDP）的本地地址、远端地址与状态；右上角下拉框可筛选
  「全部 / TCP / UDP / 已建立」

### 5.11 指标录制与导出（Perf / Network 标签）

Perf 与 Network 面板右上角提供「导出」与「开始录制」两个按钮（两面板功能对称）。

**录制（缓存态落盘）**：

- 点「▶ 开始录制」后，该设备的采样点开始批量写入服务端 SQLite（`perf_samples` / `network_samples` 表），按钮旁出现「REC · N 行」徽标实时显示已落盘行数
- 点「⏸ 停止录制」结束并弹出「录制已停止，本次落盘 N 行」；已落盘数据继续保留在缓存中，可供后续导出
- 录制会在以下情况自动停止（停止原因可在徽标悬停提示中查看）：
  - 设备断连 / 失联（`device_lost`）
  - 管理员关闭录制总开关（配置热重载，`config`）
  - 服务关闭（`shutdown`）
- 管理员可在 `config/settings.yaml` 中把 `metrics.recording` 设为 `false` 全局禁用录制（此时点「开始录制」会被服务端拒绝）
- 缓存数据由服务端自动清理：超过保留天数（默认 7 天）或总行数超上限（默认 50 万行）时删除最旧数据

**导出**：

- 「导出」下拉提供四种组合：CSV（暂存）/ JSON（暂存）/ CSV（缓存）/ JSON（缓存）
- 暂存（buffer）= 页面正在展示的内存数据快照；缓存（cache）= 录制落盘的 SQLite 数据，可选择导出从录制开始以来的全部历史
- 下载为 CSV / JSON 文件；CSV 首列 `ts` 为时间戳、`ts_iso` 为本地时间格式便于人工核对
- Perf 面板的 CSV / JSON 导出含进程 CPU 明细与电池温度/电压/健康字段（追加在文件末尾，
  既有字段与排列顺序不变）；Network 面板导出不受影响
- 若所选来源无数据会提示「无数据可导出」

### 5.14 设置页（参数设置 / 运行环境 / 检查更新）

入口：顶部导航「设置」（路径 `/settings`）；设备详情页右上角「设置」按钮会带着当前设备跳转，
并自动聚焦「设备级参数覆盖」表单。页面包含四张卡片：运行参数、生效参数、运行环境、设备级参数覆盖。

**运行参数卡**（保存位置：`config/user.yaml`，见本节末尾「user.yaml 手改」）：

- 串流段：最大分辨率（0-4096，0 表示不缩放）、起始码率（1M/2M/4M/6M/8M）、
  帧率（1-120）、编解码（h264/h265，见下文 h265 说明）、自适应码率开关
- 录屏段：录屏码率（1M/2M/4M/6M/8M）、时长上限（1-1800 秒）
- 每段各有「保存」与「重置为出厂默认」按钮；重置 = 删除该段的用户设置、回到出厂默认
- 生效语义（保存时页面有明确提示）：
  - **串流参数：保存后下次连接生效**——已在投屏中的连接不受影响，断开重连后按新参数启动
  - **录屏参数：立即生效**——每次开始录屏时读取当前值，保存后对下一段录屏即生效

**生效参数卡**（只读）：展示串流/录屏各项的当前实际生效值与来源徽标——「出厂默认 / 用户设置 /
环境覆盖」三种，一眼可辨某项参数来自哪里（例如被环境配置文件 `{APP_ENV}.yaml` 覆盖时显示
「环境覆盖」）。

**运行环境卡**（只读）：显示 scrcpy-server 版本、adb 版本、jar 文件路径与 adb 路径
（长路径折叠显示，点开可查看完整路径）。卡片内有「检查更新」按钮（见下）。

**h265 编解码**：

- 出厂默认 h264，行为不变
- h265 选项仅当浏览器支持 HEVC 解码（WebCodecs 探测通过）时才可选；不支持时置灰并提示
  「当前浏览器不支持 h265 解码，已禁用」
- 设备能力限制（重要）：h265 还要求设备端具备 HEVC 编码器。经真机验证，测试的三台设备
  均只有 H.264/VP8 编码器——在无 HEVC 编码器的设备上选择 h265，投屏会**启动失败**
  （设备详情页显示连接错误信息），工具不会自动回退 h264。此时请回到设置页把 codec
  改回 h264（全局或该设备覆盖均可）后重新连接

**设备级参数覆盖卡**：

- 下拉选择一台设备后，可为其单独设置串流参数（例如给性能较弱的设备降分辨率/帧率，
  或给某台设备单独选 h264）
- 「保存该设备覆盖」写入该设备专属覆盖（下次连接生效）；「清除该设备覆盖」删除该设备的
  全部覆盖、回到全局参数
- 覆盖的键为设备列表中显示的设备 ID（序列号 / `IP:端口` / `emulator-*`），须一一对应；
  该设备未覆盖的项回落到全局参数

**检查更新**（运行环境卡内）：

- 仅手动点击才联网查询 GitHub 上游 scrcpy 最新发布版本，工具不会自动轮询
- 结果四种状态：上游有新版（附发布页链接）/ 已是最新 / 本地版本高于上游 / 无法检查
  （离线或网络受限时给出原因）
- 仅提示，不会自动下载或执行升级；升级 scrcpy-server 请按页面提示走工具提供方的换包升级流程

**user.yaml 手改**（进阶）：

- 设置页保存的所有改动都写入 `config/user.yaml`（绿色版为包目录 `_internal\config\user.yaml`；
  若在解压目录放置含 `base.yaml` 的 `config\` 文件夹，则以该 `config\` 为准）；
  该文件不入版本库
- 配置加载链（优先级从低到高）：`config/base.yaml → config/user.yaml → config/{APP_ENV}.yaml
  → 环境变量`
- 手改 user.yaml 后无需重启：工具每约 2 秒检查一次配置文件变化，变更自动热重载；
  仅服务端口/绑定地址等少数项目需重启服务
- 若手改把 YAML 写坏（语法错误、根节点不是键值对等），服务保留旧配置继续运行，
  设置页加载/保存时会显示错误提示（可见、不静默）
- 设备级覆盖示例（键为设备列表中显示的设备 ID，如 `192.168.8.18:5555`；stream 与
  recording 两段均可写）：

```yaml
# config/user.yaml
devices:
  192.168.8.18:5555:
    stream:
      max_size: 720
      fps: 24
    recording:
      time_limit: 120
```

### 5.15 录屏页

入口：顶部菜单「录屏」（路径 `/recordings`）；设备页录屏完成后点「查看录屏」会带设备参数跳转本页。

- 列表：展示 `data/recordings/` 目录下的历史录屏文件，每行含设备、创建时间、大小（MB）
  与「播放 / 下载 / 删除」操作按钮；按创建时间（文件修改时间）从新到旧排序；
  页头「刷新」按钮手动重拉列表（录制中的会话由设备页管理，本页不自动轮询）；
  暂无产物时显示空态提示与回设备列表的引导按钮
- 播放：点「播放」弹出播放弹层，内嵌播放器直接播放该段录像
- 下载：点「下载」由浏览器原生下载该段 MP4
- 导出 webm：播放弹层内点「导出 webm」，把录像截取前 10 秒（约 10 帧/秒）导出为
  webm 短片；浏览器不支持时该按钮置灰（仍可下载完整 MP4）
- 删除：点「删除」弹出二次确认，确认后删除并刷新列表；删除失败会提示错误不假成功——
  例如文件正被占用（一边播放一边删除）时，服务端拒绝删除并响亮报错
- 设备过滤：从设备页「查看录屏」进入时，URL 携带 `?device=<设备ID>`，本页自动只显示
  该设备的产物，顶部显示「仅看 <设备>」；点清除按钮恢复查看全部产物
- 产物保留策略：录像文件属暂存，自动清理与手动删除并存：
  - 双限自动清理：超过保留天数（默认 3 天）或总容量上限（默认 512MB）时删除最旧文件
  - 关服清盘（不变）：优雅退出服务（含界面退出）清空 `data/recordings/` 目录；
    强杀/崩溃遗留的文件在下次服务启动时自动清扫
  - 手动删除：点「删除」即时腾出磁盘空间
- 旧产物说明：本版本之前的录像文件名不含设备标识，列表中以「未知设备（旧版产物）」
  展示，播放 / 下载 / 删除不受影响

## 六、常见问题（FAQ）

### Q1：设备列表为空，看不到我的设备

- 确认数据线连接正常，且设备屏幕上已点击「允许 USB 调试」
- 在设备上重新打开「USB 调试」开关，或重新插拔数据线后再点「刷新」
- 无线连接的设备：确认设备与电脑处于同一局域网、IP 与端口填写正确，并已执行过 `adb tcpip 5555`
- 若不确定设备是否可用，可在命令行执行 `adb devices` 检查（本工具自带 adb 位于项目 `tools` 目录）

### Q2：提示「连接失败」，或连接不可达的 IP 时等待很久

- 工具会先对目标 IP 做一次 TCP 可达性探测，地址不可达时约 1.5 秒内即返回失败提示，属预期行为
- 请检查 IP 是否正确、设备是否在线、端口是否为设备实际监听的调试端口

### Q3：投屏黑屏、卡住或自动变成截图模式

- 画面左上角若出现「只读预览 · 输入不可用」徽标，说明已回退到截图模式（约 0.7 FPS）
- 常见原因：设备编码器异常（部分使用 Rockchip 芯片的设备会出现编码数秒后码流中断）、
  浏览器解码出错、网络拥塞
- 码流恢复后会自动切回 H.264；也可以刷新页面重新连接
- 自适应码率降档时会有 1-3 秒黑屏，短暂黑屏后恢复属正常现象
- 部分设备画面花屏时，可在地址栏的设备页 URL 末尾加上 `?swdecode=1` 强制使用软件解码后回车
  （实验开关，软解会占用更多 CPU）

### Q4：画面正常，但点击/滑动没有反应

- 截图模式下输入不可用，画面会显示「只读预览 · 输入不可用」徽标，此时请等待自动切回 H.264 模式
- 浏览器标签页切到后台时输入会被暂停，切回前台后恢复
- 若长时间无响应，请刷新页面重新进入设备详情页

### Q5：打开日志页后没有新日志

- 日志录制默认暂停，需点击 Logcat 标签左上角的「开始」按钮才开始接收实时日志

### Q6：端口被占用或无法访问 http://localhost:8080

- 后端默认使用 8765 端口。若该端口被占用，请在启动前后端之前，于两个终端中分别设置环境变量
  `BACKEND_PORT`（例如 `set BACKEND_PORT=9000`），再启动后端与前端；两者必须使用同一个端口值，
  前端才能把请求正确转发到后端
- 前端开发服务器固定使用 8080 端口，被占用时会启动失败，请先关闭占用该端口的程序
- 若浏览器无法打开页面，请确认两个终端窗口中的后端与前端进程都仍在运行

### Q7：可以用别的浏览器吗

- 请使用 Chrome 最新两个稳定版。工具依赖 WebCodecs 等 Chrome 特性，其他浏览器未做验证；
  若浏览器不支持 H.264 解码，会自动回退到截图模式（画面更新频率与可用功能都会下降）

### Q8：修改代码/配置后如何生效

- 配置文件（`config/base.yaml`、`config/user.yaml` 与当前环境的 yaml）改动后会自动热重载
  （每约 2 秒检查一次），无需重启；仅服务端口/绑定地址等少数项目需重启服务（服务端会记录告警）
- 设置页保存的参数即写入 `config/user.yaml`，同样自动热重载
- 代码改动需重启对应的进程（后端 `python run_server.py`，前端 `npm run dev`）

### Q9：设置里选了 h265 后投屏失败/无法连接

- 常见原因：设备端没有 HEVC 编码器（不少设备仅有 H.264/VP8 编码器）。此时设备端会直接
  启动失败，工具不会自动回退 h264
- 处理：到设置页把 codec 改回 h264（可全局修改，或仅在该设备的「设备级参数覆盖」卡中修改），
  再重新连接设备；浏览器不支持 HEVC 解码时 h265 选项本就置灰不可选

### Q10：起流时提示「设备上检测到已在运行的 scrcpy 会话」

- 含义：起流前检测到设备端已有 scrcpy 服务进程占用了推流通道，为避免连到错误会话已阻断本次起流
- 提示判为「上次会话异常退出的残留进程」时（本软件残留）：重启设备即可清除；
  用其他工具（如 scrcpy 桌面版）关闭该会话后重试亦可
- 提示为「可能是其他工具正在使用」时：先确认是否有同事/其他电脑或 scrcpy 桌面版连着该设备，
  让对方断开后重试；无法定位占用方时重启设备可清除
- 正常关闭本软件的会话不会有此提示（停止投屏时会自动清理设备端进程）

### Q11：设备列表显示红色「无响应」标签怎么办

- 含义：设备网络是通的（能连接上），但设备端 ADB 命令持续超时——常见于设备负载过高、
  长时间未重启导致 adbd 卡死，或系统响应极慢
- 影响：此时截图、缩略图与投屏会失败或黑屏，列表中的型号/版本/电量为上次成功查询的
  缓存值（整行置灰即表示这一点）
- 处理：先检查设备负载与运行状态，重启设备是最有效的恢复手段；重启后可在命令行执行
  `adb shell echo ok` 探活，秒回即恢复正常，再回到页面点击「刷新」，标签会回落为「在线」
- 偶发慢但可用的设备（如低性能工业屏）也会短暂出现此标签，不影响正常使用，查询恢复后自动消失

## 七、已知限制

- 运行平台：仅 Windows 10/11 经过实测；Linux / macOS 未验证。Docker 相关配置为开发参考，
  未在容器中实测，不作为发布方式
- 浏览器：仅支持 Chrome（最新两个稳定版）
- 投屏回退：部分设备（如搭载 Rockchip 芯片的设备）存在编码器差异，投屏可能回退到截图模式
  （约 0.7 FPS 且不可操作），或出现画面旋转等差异
- 自适应码率：网络状况变化触发码率档位切换时，会有 1-3 秒黑屏
- 绿色免安装 exe：即 Windows 绿色版，使用与故障排查见随包《Windows exe 发布说明》；
  本手册第三章为源码运行方式
- 文件管理：写操作（上传/重命名/删除）仅限 `/sdcard` 与 `/data/local/tmp`；设备端存量文件
  名含非 UTF-8 字节时，页面显示为替换字符，对该类文件的重命名/删除/下载可能失败
- 日志与数据默认保存在项目 `data` 目录下的 SQLite 数据库中，日志按时间与容量自动清理
- 参数设置：多个设置保存请求同时提交时按「后保存的覆盖先保存的」合并（设置页写接口无并发
  合并锁），建议逐个保存
- 参数设置：配置文件目录只读（如绿色版放在 Program Files 等受保护目录）时，保存设置会报错，
  页面会显示错误信息（不会静默忽略）
- 投屏 h265：需要设备端具备 HEVC 编码器；无 HEVC 编码器的设备上选择 h265 会导致投屏启动失败，
  工具不会自动回退 h264（详见 5.14）
