## 日期
2026-09-09

## 问题描述
scrcpy-server 启动成功，连接成功，读取设备信息成功，但没有视频数据流。

## 已验证的事实

### 1. scrcpy-server.jar 版本正确
- 文件 MD5: `7223f4d0753e9a9ebc43d10c51d01439`
- 与官方 v4.1 发布版本完全一致
- 文件大小: 733706 字节 (717 KB)

### 2. scid 格式正确
- 我们的实现：8 位十六进制（如 `3a8098ba`）
- 官方源码：`Integer.parseInt(value, 0x10)` - 基数 16（十六进制）
- 官方 C 代码：`ADD_PARAM("scid=%08x", params->scid)` - 格式 `%08x`

### 3. socket 名称正确
- 我们的实现：`scrcpy_3a8098ba`（包含 scid）
- 官方源码：`"scrcpy_%08x"` - 必须包含 scid

### 4. 连接流程正确
服务器日志显示：
```
[OK] scrcpy-server 启动
[OK] port forward 设置成功
[OK] 连接到 server socket
[OK] 读取设备名: rk3288
[OK] 读取设备 ID: 0068323634800000...
[FAIL] 没有视频数据
```

### 5. 服务器进程在运行
```
shell     18613 18611 1507148 88848 __skb_recv a5c5a704 S app_process
shell     18731 18729 1515032 92300 SyS_epoll_ b43c27a4 S app_process
```
发现有两个 app_process 进程，已清理。

## 尝试过的修复

1. ✓ 修正 scid 格式从十进制到十六进制
2. ✓ 修正 socket 名称从固定 "scrcpy" 到包含 scid
3. ✓ 添加 `video=true` 参数
4. ✓ 清理多个 server 进程

## 根本原因分析

根据日志，server 启动成功、连接成功、读取设备信息成功，但没有发送视频数据。可能的原因：

1. **视频编码器初始化失败** - server 可能无法访问硬件编码器
2. **参数顺序或格式问题** - server 对参数顺序敏感
3. **缺少必要参数** - 可能需要额外的编码器配置
4. **Android 版本兼容性** - 设备运行 Android 7.1.2，可能不支持某些特性
